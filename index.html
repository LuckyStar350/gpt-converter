    本机运行 · 默认联网刷新 · 不使用第三方转换服务RT · Sub2API · CLIProxyAPI

    使用说明

    1. 粘贴内容，或导入多个 JSON、TXT、JSONL 文件。也支持文件夹与 ZIP。
    2. 选择目标格式，点击「联网转换」或 Ctrl / ⌘ + Enter，工具默认通过本机服务使用 RT 获取凭据并转换。
    3. RT 下载为 TXT，Sub2API 下载为合并 JSON。CPA 每个账号一个 JSON，多个账号下载为 ZIP。

    请双击「启动工具.bat」。需要代理时展开「网络设置」并填写 HTTP、HTTPS 或 SOCKS5 代理地址；client_id 优先取输入凭据，也可手动指定。

    联网刷新成功后，输入会更新为最新凭据，切换格式不会再次刷新。失败项保留原数据并逐项报告；缺少访问令牌或账号 ID 的项目不会生成 CPA / Sub2 占位凭据。新 RT 请及时下载保存；页面刷新会清空输入。「停止后续刷新」会等待已发送的请求完成，再生成已完成的结果。

    CPA 批量结果显示当前文件，使用文件列表切换预览。「复制结果」复制当前文件的完整内容，包含未脱敏 Token。

    自动去重按 Token 与账号 ID 判断，重复项保留字段更完整的一项。取消去重可保留全部输入项。同一批相同 RT / client_id 只刷新一次；本次已经刷新的凭据再次转换时直接复用。

    「保留扩展字段」把源格式独有的配置放入 _gpt_converter 扩展，便于转回。目标服务重新导出时可能移除扩展。RT 文本只包含 refresh_token。

    格式转换在浏览器本地完成。联网转换时 RT 通过本机服务发往 auth.openai.com/oauth/token，不上传到第三方转换网站。本机服务不将凭据写入磁盘或请求日志，只在内存中短时缓存新旧 RT 对应的成功结果以避免重复轮换；停止服务后清空缓存。页面不使用浏览器存储保存账号。

    「检测连接」发送虚构 RT，不发送输入中的凭据。检测显示 HTTP 401 且 OAuth 服务可达，是网络正常的结果；HTTP 403 表示出口或网络验证被拒绝。RT 已被使用无法通过更换代理恢复，请使用最新凭据或重新登录。

    仅支持 OpenAI / ChatGPT OAuth 账号。单文件最多 20 MB，导入内容合计最多 64 MB，每次最多 5000 个账号。ZIP 支持 Store / Deflate，不支持加密、分卷或 ZIP64。推荐新版 Chrome / Edge。

    GitHub 参考项目见同目录 README.md。示例 Token 为虚构数据，不会成功刷新。
